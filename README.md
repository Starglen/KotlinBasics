# Kotlin Basics

A beginner-friendly Kotlin study repo designed to help you learn core programming concepts through small, runnable examples.

## What this repo covers

- Variables and data types
- Operators and expressions
- Conditionals and loops
- Functions and parameters
- Classes and objects
- Collections and list operations
- Null safety
- Small practice exercises

## Repo structure

- `src/Main.kt` — main runnable example file
- `src/*.kt` — topic-based Kotlin lesson files

## Quick start

1. Install Kotlin or use IntelliJ IDEA.
2. Open this project in IntelliJ or run:

```bash
kotlinc src/*.kt -include-runtime -d kotlin-basics.jar
java -jar kotlin-basics.jar
```

## Suggested learning path

1. Variables and data types
2. Input, output, and string formatting
3. Conditionals and loops
4. Functions and return values
5. Classes, inheritance, and constructors
6. Collections and filtering
7. Null safety and error handling
8. Build a small project using everything you learned

## Practice ideas

- Write a function that checks if a number is prime.
- Create a list of students and print only those who passed.
- Build a tiny To-Do app using a data class and functions.
- Add a class for a `BankAccount` with deposit and withdraw logic.

## Why this repo is useful

This repo is intentionally structured as a learning resource, not just a collection of random scripts. Each file focuses on a concept, and the examples can be used as reference material while you study Kotlin.
